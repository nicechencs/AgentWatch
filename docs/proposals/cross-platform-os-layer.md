# 跨平台包：统一系统接口（linux / macos / windows）

本文件随 `feat/cross-platform` 开单，记录这一包的结构约定；接口代码按下面的约定逐步推上来。

## 收进统一接口的部分

- 启动并挂起程序：拆成两步，先启动并挂住（`spawn_suspended`），接管成功后再放行（`release`）。挂住期间任何一步失败都结束这个程序，不留没人监控的程序。
- 读进程身份和进程表：真实 / 有效 / 保存三个用户身份、启动时间。
- 回收退出码：只等后台自己启动的那个子进程；采样发现它已经不在时，也走同一个回收函数。
- 认出连接方是谁：结果只有「认出是谁」和「认不出」两种，认不出一律拒绝，绝不退回用后台自己的身份（Windows 绝不用服务账户）启动程序。
- 数据目录权限：Linux / macOS 归 root，Windows 只给 SYSTEM 和管理员。

## 约定

- 系统专属代码只放在各自的 `linux/`、`macos/`、`windows/` 里，编译时按系统挑；共用代码里不再按系统分支。
- 还没做的系统，在它自己的实现里返回明确的「这个系统还不支持」，界面和 `aw doctor` 据此显示，不返回空结果。
- Linux 搬进新结构后行为不变：老测试一条不删、断言一条不改。
- 一套按接口写的共用测试，三个系统都跑：退出码 7、程序名填错、`@last` 隔离、停止记录后回收、后台重启。
